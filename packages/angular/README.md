# keystone-financial-tools-angular

Angular services and components for the Keystone drawing tools. It only shows what
`keystone-financial-tools-core` decides; it has no drawing logic of its own. It works with zone.js and
without it. Peer dependencies: Angular 22 or newer and rxjs 7.

Version 0.1.0. Licensed UNLICENSED (proprietary).

```bash
npm install keystone-financial-tools-angular
```

## Documentation

See the Angular getting started page of the documentation site (`packages/docs`) and its guides. The
API reference is generated from this package.
