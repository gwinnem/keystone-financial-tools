# keystone-financial-tools-react

React hooks and components for the Keystone drawing tools. It only shows what
`keystone-financial-tools-core` decides; it has no drawing logic of its own.

Version 0.1.0. Licensed UNLICENSED (proprietary).

```bash
npm install keystone-financial-tools-react
```

## Documentation

See the React getting started page of the documentation site (`packages/docs`) and its guides. The API
reference is generated from this package.
