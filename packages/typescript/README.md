# keystone-financial-tools-typescript

Framework-free API for the Keystone drawing tools. Re-exports `keystone-financial-tools-core` and adds
persistence: asynchronous repositories (memory, Web Storage, IndexedDB), auto-save, safe loading, and
export and import of drawings as text.

Version 0.1.0. Licensed UNLICENSED (proprietary).

```bash
npm install keystone-financial-tools-typescript
```

## Documentation

See the TypeScript getting started page and the guide *Save and load drawings* on the documentation
site (`packages/docs`). The API reference is generated from this package.
