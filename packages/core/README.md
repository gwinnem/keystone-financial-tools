# keystone-financial-tools-core

Framework-neutral core of the Keystone drawing tools: the drawing model, validation, the drawing
store, history, the saved document format, the `DrawingHost` contract a chart implements, and the
interaction engine behind the tools. A `/testing` entry has a mock host and the host conformance kit.

Version 0.1.0. Licensed UNLICENSED (proprietary).

```bash
npm install keystone-financial-tools-core
```

## Documentation

See the documentation site (`packages/docs`): the host guide, the keyboard reference, one page per tool,
and the API reference generated from this package. The design is in [SDS](../../specs/SDS.md) and the
changes in [CHANGELOG](../../CHANGELOG.md).
